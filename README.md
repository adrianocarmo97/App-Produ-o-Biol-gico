# Drone | Produção

App de gestão de produção agrícola com drone (Trichogramma / Cotesia).

## Como gerar o APK
1. Suba esta pasta inteira para um repositório no GitHub (branch `main`).
2. Abra a aba **Actions** → **Build APK** (roda sozinho a cada push; ou clique em *Run workflow*).
3. Quando terminar (3 a 6 min), abra a execução e baixe **drone-producao-apk** em *Artifacts*.
4. Descompacte e instale `app-debug.apk` no celular (permita "fontes desconhecidas").

O app em si fica em `www/index.html`.
